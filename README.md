# PERN-in-typeScript
postgresQL + Express + React + Node in TypeScript
## configure the postgresQL with local machine
 - download the postgresQL stable version and pgadmin for user interface via postgresapp.com and follow the instruction to configure postres server and create role and db
 - install docker desktop to see the container and its images
 - run npm i to install all dependencies
## to start the dev server
- npm run dev
